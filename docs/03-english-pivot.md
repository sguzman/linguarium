# 03 — English as Semantic Pivot

## Decision

English is Linguarium's default practical interlingual pivot.

A sense in an active non-English language should normally be allowed to acquire an English gloss or explanatory definition. Cross-language comparison can then use shared concepts and English footholds rather than requiring direct pairwise translation between every language.

This converts an N×N maintenance problem into approximately N×1 for basic accessibility.

## What the pivot solves

Given several languages, direct pairwise translation creates many maintenance surfaces.

A pivot permits:

~~~text
Spanish  ->
German   ->
Russian  ->  English semantic footholds / shared concepts
Japanese ->
French   ->
~~~

The system may still store direct non-English relations when they are useful, attested, or pedagogically revealing.

## English is not canonical reality

The following assumptions are prohibited:

~~~text
English word == concept
English grammar == universal grammar
English gloss == exact sense
same English gloss == synonymous non-English senses
translation == semantic identity
~~~

Two words can receive the same English gloss while encoding importantly different concepts. The ontology must preserve those distinctions.

## Foothold types

A non-English sense may have:

1. equivalent — a strong ordinary translation in context;
2. approximation — useful but semantically incomplete;
3. explanation — English prose rather than a lexical equivalent;
4. literal rendering — mirrors source structure for analysis;
5. idiomatic translation — natural target-language expression;
6. untranslatable marker — no compact English equivalent asserted.

These types may coexist.

## Comparative rule

Cross-language comparison should prefer a justified Sense -> Concept <- Sense relation when a shared concept exists.

English glosses help humans navigate the relation but do not create it automatically.

## Future multilingual glossing

Direct Spanish-to-French, Japanese-to-Chinese, and other non-English glosses are permitted later because they may expose useful structural relationships. They are optional enrichment, not baseline completeness requirements.
